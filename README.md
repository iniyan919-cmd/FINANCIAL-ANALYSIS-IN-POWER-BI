# FINANCIAL-ANALYSIS-IN-POWER-BI
## OVERVIEW
Power BI Financial Analysis Dashboard 📊 | Interactive dashboard analyzing sales, profit, gross sales, and units sold across multiple countries. Features dynamic visualizations, trend analysis, KPI tracking, and data-driven insights to support strategic business decisions.
## Features
- Monthly Profit Analysis
- Country-wise Profit Distribution
- Gross Sales & Product Performance Analysis
- Sales Summary by Country
- Gross Sales vs Units Sold Trends
- Country-wise Units Sold Distribution
